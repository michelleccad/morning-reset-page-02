# Morning Reset ☀️

A mobile-first personal morning routine page.

## GitHub Pages
1. Create a GitHub repository (for example `morning-reset`).
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Open the generated GitHub Pages URL in Safari.
7. Tap **Share → Add to Home Screen**.

No build step or dependencies are required.

## Notes
- Progress is stored locally in the browser using localStorage.
- The 30-day journey advances when all five morning steps are completed.
- Bible verses rotate by program week.
